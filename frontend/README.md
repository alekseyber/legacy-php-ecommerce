# Фронтенд витрины

Отдельный проект сборки: webpack + Babel + SCSS. Собранные файлы уходят в `../public/assets`.

## Что внутри

- `src/js/app/` — слой компонентов: базовый класс, слой данных (корзина, страница, быстрый просмотр, модальные действия, reCAPTCHA), 21 UI-компонент, обёртка над `fetch` с классом ошибки;
- `src/js/dom/` — собственный слой над нативными событиями, чтобы компоненты не зависели от jQuery;
- `src/js/bootstrap-md*`, `src/js/components/` — адаптированные сторонние библиотеки (галерея, datepicker, маска ввода);
- `src/scss/` — свои стили: 6 857 строк;
- `src/*.html` — HTML-шаблоны страниц.

## Поколения разметки

В `src/` лежат два варианта главной страницы, и это не дубликаты:

- `index.html` — рабочая версия 2021 года: 82 поднятых компонента, быстрый просмотр, typeahead;
- `index-static.html` — ранняя версия: чистая HTML-вёрстка без компонентного слоя (0 `data-selector`), по ней видно, откуда слой вырос.

Промежуточные копии в архив не попали.

## Сборка

```
npm install
npx webpack --mode production
```

В `webpack.config.js` активен только шаблон `index.html`; блоки для остальных страниц закомментированы — они собирались по одной в разное время.
